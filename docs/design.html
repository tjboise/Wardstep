WARDSTEP

在一张不断扩展的格子地图上放置符文，守卫中心核心。小人自动巡逻，踩到格子时触发效果。怪物从四面涌来。买铲子，挖格子，堆符文，撑到最后。

核心机制

格子系统

地图由若干格子组成，每个格子是一个符文槽位。小人沿覆盖所有格子的环形路径自动巡逻，踩到某格时触发该格的符文。怪物从四个方向的边缘涌入，目标是地图中心的核心。核心 HP 归零，游戏结束。

起始状态是 2×2 田字格，核心位于四格交汇的中心点。购买铲子可向任意方向扩展一格，获得新的符文槽位，同时让怪物需要走更远的路。

核心洞见：小人是触发器，不是单位。格子的位置决定了符文的触发频率——靠近路径拐角的格子被踩得更频繁。扩展格子时，新格子加在哪里直接改变整条路径的节奏。

铲子 · 地图扩展

铲子系统

铲子在商店中随机刷新，不是每次都有。购买后，地图高亮所有合法的扩展位置（必须与现有格子共享一条边），玩家选择一格挖出来。新格子初始为空槽位，需单独购买符文放入。

铲子 = 新符文空间 + 外围防线延伸。越靠外的格子，怪物到核心的路越长——但路径也更长，每张符文的触发频率略降。扩展时机是战略决策，不是免费送的。

扩展规则：新格子必须与至少一个现有格子共享整条边（不能斜角）。扩展后路径自动重新规划，保证小人经过所有格子。

经济系统

金币与商店

怪物死亡时在原地掉落金币图标，自动收集，有拾取动画反馈。每一小关 / 精英关 / Boss 关结束后各开一次商店。

遗物

遗物系统

遗物是永久被动效果，来自精英关击败 / 商店稀有刷新。它们是每局构筑风格差异化的核心来源。首发目标约 60 件，每局约 15–20 件可获得。
