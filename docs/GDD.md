## 1. 一句话介绍

玩家**自由拼接**最多9个格子，组成任意形状的巡逻路线，骑士沿路径自动踩格触发武器，抵御从四面涌来的怪物守卫城堡。Roguelite 肉鸽 · 空间策略 · 防御。

**类型：** Roguelite · 空间策略 · 塔防  
**平台：** PC（Steam）  
**引擎：** 待定（推荐 Godot）

---

## 2. 核心机制

### 格子系统（玩家自由摆放）

玩家将最多 **9个格子** 自由拼成任意形状，格子连接关系决定骑士的巡逻路径。没有固定3×3布局——玩家决定一切。

**合法形状举例：**
```
L形           十字形        蛇形
■ ■           　■           ■
■             ■ ■ ■         ■ ■
■ ■           　■           　 ■
```

格子形状即路径设计：骑士按格子的连接顺序循环巡逻，踩到格子时触发该格武器。

### 骑士巡逻

骑士沿格子连接路径循环往复，踩到某格时触发该格武器（若在冷却中则跳过）。  
触发逻辑：
```
骑士进入某格
  → 该格有武器 且 武器冷却结束？
    → 是：触发武器效果，进入冷却
    → 否：跳过，继续走
```

### 敌人行动

怪物从地图边缘生成，自动寻路向城堡移动。抵达城堡时造成伤害（城堡HP归零则失败）。不同关卡出兵方向不同（单侧/双侧/三路/四路）。

## 3. 武器系统

每个格子可放置一件武器，骑士踩格时触发。武器有三个等级（Lv1/Lv2/Lv3），通过商店升级。

### 武器列表

| 武器 | 类型 | 基础CD | Lv1效果 | Lv3特性 |
|------|------|--------|---------|---------|
| 铁剑 ⚔ | 剑/近战 | 1.2s | 伤害4 | 双击·第二刀击退 |
| 猎弓 🏹 | 弓/远程 | 1.8s | 1箭·伤害3 | 3箭·穿透全路径 |
| 火焰法杖 🪄 | 法系/范围 | 2.2s | 伤害5·小范围 | 双爆·大范围 |
| 骑士盾 🛡 | 防御 | 2.0s | 护盾8 | 护盾22·脉冲击退 |
| 钢矛 🗡 | 刺击/穿透 | 1.5s | 穿透1·伤害5 | 全穿透·减速 |
| 陷阱 ⚙ | 陷阱/持续 | 放置即激活 | 触发1次 | 永久·爆炸溅射 |

完整设计见 [武器图鉴](../design/weapons/)。

## 4. 附魔系统

每个格子可独立附加一种附魔，叠加在武器效果上。附魔也有三个等级，独立升级。

| 附魔 | 核心效果 | Lv3特性 |
|------|---------|---------|
| 🔥 火焰 | 点燃·灼烧2/s·2s | 爆燃：燃烧结束时范围爆炸 |
| ❄ 冰霜 | 减速30%·叠3次冻结 | 冻结2.5s·脆弱+35%·碎裂12伤 |
| ⚡ 雷电 | 30%弹跳·最多2次 | 60%弹跳·4次·留雷痕 |
| ☠ 毒素 | 1.5% maxHP/s·3s | 2.8% maxHP/s·死亡扩散 |
| ✦ 强化 | 武器伤害+25% | 伤害+60%·首击+20%·CD-8% |

完整设计见 [附魔图鉴](../design/enchants/)。

## 5. 职业系统

游戏开始时选择职业，影响初始武器和专属被动效果。

| 职业 | 专属被动 | 武器倾向 | 初始武器 |
|------|---------|---------|---------|
| 剑士 ⚔ | 武艺精通：剑/刺击+40%，命中后加速 | 剑类/刺击 | 铁剑×2 |
| 弓手 🏹 | 穿云箭：弓类射程无限，穿透所有目标 | 弓类/陷阱 | 猎弓×2 |
| 法师 🪄 | 法力共鸣：法系CD-30%，连续触发叠加共鸣（最多3层+15%） | 法系/弓类 | 火焰法杖+猎弓 |
| 守卫 🛡 | 铁甲意志：城堡HP+30%，盾护盾值×2 | 防御/刺击 | 骑士盾+钢矛 |

完整设计见 [人物图鉴](../design/characters/)。

## 6. 遗物系统

精英关击败后三选一，永久生效，最多持有5个。分攻击/防御/格子/骑士/特殊五类。

**典型遗物：**
- 战争印记：所有武器伤害+12%
- 血月护符：每损失10% HP → 武器伤害+6%（最多+30%）
- 扩展蓝图：格子槽位从9增加到11
- 黑暗契约：HP-25%，武器伤害+35%，CD-10%

完整设计见 [遗物图鉴](../design/relics/)。

## 7. 经济循环

```
波次中：怪物死亡 → 掉落金币
波次结束 → 商店开启
商店 → 买武器 / 升级武器 / 升级附魔 / 买遗物 / 刷新
```

### 商店售卖

| 商品 | 价格参考 |
|------|---------|
| 武器（Lv1） | 10–20 金 |
| 武器升级（→Lv2/3） | 15–25 金 |
| 附魔施加 | 10–18 金 |
| 附魔升级 | 12–20 金 |
| 刷新商店 | 初始1金，每次+1 |
| 出售武器 | Lv1=40%·Lv2=65%·Lv3=100% 原价 |

## 8. 关卡结构（8大关）

每大关包含：
```
大关
├── 小关1（普通波次）→ 商店
├── 小关2（强化波次）→ 商店
├── 精英关 → 精英Boss → 遗物三选一
└── Boss关 → 终章Boss → 进入下一大关
```

### 8大关一览

| 关卡 | 主题 | 地形特效 | 新机制 |
|------|------|---------|--------|
| Act 1 | 古城外墙 | 无（标准地形） | 教学，单侧出兵 |
| Act 2 | 幽暗森林 | 树木遮蔽（格子-2） | 双侧出兵，爆炸兵登场 |
| Act 3 | 冰封雪原 | 冰面加速骑士+30% | 双侧同时出兵 |
| Act 4 | 炙热熔岩 | 熔岩格不可用（格子-2） | 地形分割，三路出兵 |
| Act 5 | 沙漠废墟 | 流沙：武器CD+25%/触发窗口延长 | 三路出兵，亡灵复苏 |
| Act 6 | 雷暴高地 | 随机落雷（武器失效3s或造成AOE伤害） | 雷击双刃剑机制 |
| Act 7 | 深海遗迹 | 潮汐每30s淹没2格（武器不触发） | 方向反转Boss |
| Act 8 | 天空要塞 | 疾风偏转远程武器20% | 四路出兵，最终决战 |

完整关卡设计见 [关卡图鉴](../design/stages/)。

## 9. Boss设计

每大关含2位Boss：精英Boss（获取遗物）和终章Boss（过关）。每位Boss有独特的场地技能机制。

**16位Boss技能关键词：**

## 10. 局外成长

**设计原则：** 解锁「可能性」而非「数值」。初始内容已足以通关，后续解锁带来新策略，不提供数值补贴。

### 解锁进程

每通关一大关，新一批武器/附魔/遗物/职业进入卡池。初始提供 3 武器、2 附魔、8 遗物、2 职业，通关 Act 1–8 陆续解锁剩余内容（含 4 件新武器）。

### 挑战诅咒

玩家主动叠加的局部规则限制（最多 3 条），难度越高奖励越丰厚：

| 诅咒 | 效果 | 难度 |
|------|------|------|
| 铁血令 | 格子上限 9→7 | ★ |
| 封印令 | 附魔系统关闭 | ★★ |
| 流亡令 | 商店不出现职业倾向武器 | ★ |
| 混沌令 | Boss随机获得额外技能 | ★★★ |
| 破产令 | 禁止出售武器 | ★★ |
| 速攻令 | 每小关有时间限制 | ★★ |
| 孤勇令 | 遗物上限 5→2 | ★★★ |
| 裁决令 | 每关随机禁制一种武器 | ★★★ |

叠加 2 条+20 金初始资金；叠加 3 条给予随机稀有起始遗物。

### 组合记忆

存活 Act 5+ 后，记录本局持有最久的遗物组合。两件遗物被标记为「有缘」，下一局在商店同时出现概率 +40%。让发现过的强力联动更容易复现，鼓励主动追求特定构筑路线。

完整设计见 [局外成长](../design/meta/)。
