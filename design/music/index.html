技术说明
所有音乐由 Web Audio API 实时合成，无需音频文件。采用「看前调度器」（look-ahead scheduler）：setInterval(50ms)，每次提前 0.3 秒排队音符，避免界面卡顿导致的断音。 drone 振荡器持续运行，切换时调用 .stop() 并重建；已排队的短音符自然消亡。源码见 demo/music.js。
