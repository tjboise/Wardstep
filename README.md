# Wardstep

一款 Roguelite 空间策略防御游戏，目标平台 Steam。

玩家**自由摆放**最多 9 个格子，拼出任意形状的巡逻路线（L形、十字、环形……）。骑士自动沿路径踩格，触发格子上的武器攻击敌人；每个格子可独立附魔强化效果。选择不同角色职业，与武器类型产生天然协同。8大关，地形各异，步步为营，守卫城堡。
